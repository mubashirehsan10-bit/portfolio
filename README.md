# Mubashir Ehsan — Developer Portfolio

A terminal-themed, premium developer portfolio built with vanilla HTML, CSS, and JavaScript — no frameworks, no build tools, just clean handcrafted code.

🔗 **Live Site:** [(https://mubashirehsan10-bit.github.io/portfolio/)]
---

## ✨ Features

- **Terminal-style hero section** with an animated typing effect (`$ whoami` sequence)
- **3D orbit-style project carousel** — navigate via buttons, keyboard arrows, mouse wheel, or touch swipe
- **Expandable project cards** with sub-project breakdowns (e.g. grouped internship work)
- **Custom cursor** with hover/click states, matching the terminal aesthetic
- **Scroll-triggered animations** for sections (About, Skills, Experience, Contact)
- **Fully responsive** — optimized layouts for desktop, tablet, and mobile
- **Zero dependencies** — pure HTML/CSS/JS, fast load times, easy to deploy anywhere

---

## 🛠️ Tech Stack

- **HTML5** — semantic structure
- **CSS3** — custom properties (CSS variables), gradients, animations, flexbox/grid
- **Vanilla JavaScript** — DOM manipulation, event handling, no external libraries
- **Fonts:** Inter, JetBrains Mono
